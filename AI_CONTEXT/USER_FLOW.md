# 🌊 User Flow

## Luồng sử dụng thực tế (Macro to Micro)
1. **Nhìn số tổng (Dashboard)**: Theo dõi biến động doanh thu, nhận diện rủi ro/cơ hội.
2. **Drilldown (Lọc)**: Click vào các thẻ KPI hoặc bảng Heatmap để khoanh vùng (Cụm/Bưu cục/Nhân viên).
3. **Phân tích (Customer List)**: Xem danh sách chi tiết các khách hàng đang bị rớt doanh thu hoặc cần chăm sóc.
4. **Hành động (Action)**: Giao task cho nhân viên hoặc tự mình gọi điện cứu chữa.

## Dashboard Usage
- Cập nhật số liệu vào mỗi buổi sáng.
- Cung cấp cái nhìn nhanh gọn thông qua Elite Pulse.
- Hỗ trợ ra quyết định điều hành tức thời thay vì chờ báo cáo cuối tháng.
